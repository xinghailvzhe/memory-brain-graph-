# 记忆-脑-图 · memory-brain-graph

把本地记忆库渲染成一张可缩放探索的星空脑图，并把「记忆 / 会话 / 插件 / 技能」摆进同一套几何语言。
纯本地运行：自带 Python 标准库服务 + DSH 插件，无外部依赖、不联网、不上传任何数据。

> 仓库里目前只有 README 与 LICENSE，**完整插件在右侧「 Releases → v0.5.0 」的附件里**。

## 下载

右侧 **Releases** → `v0.5.0` → 下载 `memory-brain-graph-0.5.0.zip`（完整插件 + 说明）或 `说明-0.5.0.zip`（仅文档）。

## 功能

### 记忆脑图（默认视图）
- 六层记忆环（灵魂 / 用户 / 准则 / 项目 / 事实 / 经验 / 话题）绕中心球公转，节点按重要度缩放
- 悬停节点看「层名 + 标题 + 摘要」，点击打开原文
- 记忆脉冲、环标签、小行星（时间桶）、视角自转 / 重置

### 记忆时钟（镜头缩远分层进入）
- 记忆碎片自动组装成一座黄铜机械钟：齿轮、星盘、指针依次落位
- **拖动表盘外圈那条细金环（外拨环）**转到任意时段，反查那段时间的会话
- 组装完成后平滑对到现实时间；拉近再拉远会重播组装动画
- 钟外挂会话碎片（如 10:20–10:50）与「进行中」标记

### 远景层（继续拉远依次浮现）
- 插件残片轨道：已装插件沿轨道排成一圈
- 技能戴森环：已装 skill 沿环排布，点开读简介
- 四特质法阵、天球内视

### 光缆树（v0.5 新增，独立视图）
- 整棵树由发光晶体堆成，没有实体树干与枝条；底部是 CPU，树从它里面长出来
- 花 = 技能（上限 30 朵）；近白色丝线 = 技能之间的前置关系（`assets/skill-deps.json`）
- 解锁判据是零件数：读 `organs/parts.json`，零件 ≥4 画成亮金，不足画成青色
- 悬停 / 点击花：技能名、简介、零件分布（感知 / 思索 / 实践）；锁定的写明怎么解锁
- 左侧小技能树面板：三态（已解锁 / 可解锁 / 锁定），点一行跳到对应那朵花

### 时间轴视图
- 点底栏「时间轴」切换：横轴创建时间、纵轴分层，看哪段时间在忙、哪段是空窗

### 三元图
- 把插件与 skill 摆进「感知 / 思索 / 实践」三轴，看偏科与信号强弱

### 自我反思（实验性，默认关闭）
- 待反思 → 已反思，一条结论一颗星，反思历史落盘不覆盖
- 左下角控制栏：自动反思与「技能自动拼装」共用一个总开关，另有「立即反思 / 立即拼装」

### 技能零件与自动组装
- `parts.py`：把每个 SKILL.md 按 `##` 章节拆成零件（感知 / 思索 / 实践）
- `assemblies.py`：找出被多个 skill 共用的执行体，按技能集合聚合成组件
- `compose.py`：一句话需求 → 三轴检索 → 缺层判定 → 装配单；`--review` 出 merge/split/extract/prune/fill 清单
- 脚本在 `assembler/`，路径可用 `MBG_WS` / `MBG_SKILLS` / `MBG_OUT` 覆盖
- 对照基线：45 技能 / 264 零件（感 50·思 117·实 72·未知 25）、assemblies=15

### 导出与入口
- 导出图（PNG）、导出网页、新窗口打开；输入框右侧「脑图」按钮 / 会话视图「脑图」页

## 安装

1. 解压 `memory-brain-graph-0.5.0.zip`
2. 把 `memory-brain-graph/` 放进 DSH profile 的插件目录，或按包内 `AI-INSTALL.md` 安装
3. 重启 DSH；入口见上
4. 需要 Python 3（DSH 桌面版自带运行时，会自动找）

包内文档：`README.md`（使用）、`AI-INSTALL.md`（给 AI 的部署说明）、`SKILL-ASSEMBLY.md`（组装脚本施工图）、`安装说明.md`、`服务器部署说明.md`。

## 数据与隐私

- 只读本地 meow-memory 记忆库与 DSH 会话日志，不联网、不上传
- 没有记忆库时软失败：服务照常起来，页面说明缺什么、去哪装
